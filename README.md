
# Git 기초 연습 프로젝트

## 프로젝트 소개
Git과 GitHub의 기본 사용법을 익히기 위한 연습 프로젝트입니다.

## 학습 목표
- Git 저장소 생성하기
- 파일 추가 및 수정하기
- 변경 사항 커밋하기
- GitHub에 코드 업로드하기

## Git 기본 명령어

| 명령어 | 설명 |
|---|---|
| `git init` | Git 저장소 생성 |
| `git status` | 현재 상태 확인 |
| `git add .` | 모든 변경 파일 추가 |
| `git commit -m "메시지"` | 변경 사항 저장 |
| `git push` | GitHub에 업로드 |
| `git pull` | 원격 저장소 변경 사항 가져오기 |
